Installation

Open the DMG and launch 코드빚다-C.app. In setup, start installation. If prompted, install Apple Command Line Tools, verify the compiler, then launch the app. C has its own instructor approval and classrooms.

Ad-hoc signed. If macOS blocks the first launch, confirm the download source and use System Settings → Privacy & Security → Open Anyway.
